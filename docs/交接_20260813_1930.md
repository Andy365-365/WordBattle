## 当前问题

正式测试 `auto_test.py` 使用 UI dump bounds 解析的坐标 `(540,773)/(540,945)/(540,1121)/(540,1285)`，命中率约 56%。选项3（第4个选项）几乎 0 命中，选项2常偏到选项3。

## 已确认的事实

### 1. 按钮 hit area 完全正常
通过扫描脚本逐像素验证，4 个选项的实际可点击范围：
- 选项0: Y=[700~846] 147px
- 选项1: Y=[869~1022] 154px
- 选项2: Y=[1045~1198] 154px
- 选项3: **下边界被脚本截断**（原扫描只到1350，实际bounds下界1375）

**关键发现**：第一次扫描的 range 上限 1350 是我拍的，导致选项3下边界被截断，中心算成 1285 而非 1298。**UI dump 的中心坐标 (540,770/946/1122/1298) 与实测几乎一致，选项3差13px是因为扫描范围不够。**

### 2. MIUI 设备安装问题
- `pm uninstall` 失败（`DELETE_FAILED_INTERNAL_ERROR`）
- `adb install -r` 弹"继续安装"确认框（10秒倒计时），`input tap` 抢时间不稳定
- **auto_install.py 正确参数**：delay=0.5s（抓对话框），等待15s（等安装完成验证）
- **scan_buttons.py 正确做法**：`force-stop` + `KEYCODE_HOME` 回桌面 + 调用 `auto_install.py`（不要 `pm uninstall`）
- App 在前台运行时 HOME key 可能被挡住，需要先 `am force-stop` 再回桌面

### 3. Log 读取
- MIUI Android 12 上 `Log.i/d` 可能被系统过滤，`logcat` 读取不可靠
- **正确方案**：读 `DebugLog` 的远程日志文件（HTTP push 到 log_receiver 8765），路径 `/data/wordbattle/logs/remote_all_20260813.log`
- `DebugLog.i()` 和 `DebugLog.d()` 均可正常写入远程日志

### 4. 背景点击事件
- `HostGameScreen.kt` 的 Column 已加 `pointerInput(Unit)` + `detectTapGestures`，空白区域点击输出 `bgTap y=坐标`
- 按钮 onClick 输出 `onAnswer idx=N`
- 两者互斥：点中按钮→onAnswer，点空白→bgTap，100% 覆盖
- **此修改用于扫描，正式版本需移除**

## 构建与运行

```bash
cd /data/wordbattle
export ANDROID_HOME=/usr/lib/android-sdk
export JAVA_HOME=/usr/lib/jvm/java-17-openjdk-amd64
/opt/gradle-8.2/bin/gradle :app:assembleDebug

# 启动日志接收器
python3 scripts/log_receiver.py 8765

# 扫描按钮坐标
python3 scripts/scan_buttons.py

# 正式测试
python3 scripts/auto_test.py
```
