### 改动点（唯一）
`PracticeSession.start()`：`records.shuffled()` 纯随机 → 加权抽样。其余链路（出题 buildQuestion、submit、连对 3 次归零、星级写库）全部不动。

### 已对齐的方案（用户已点头"行，你开始吧"，随后叫停只是要 /new）
1. **权重公式**：`weight = (1 + wrongCount) * 2^(小时数 / 24)`
   - 频率因子：答错 1 次=2 倍基础权重
   - 时间衰减：最近答错翻倍，7 天前衰减到 1/8
2. **边界情况**：
   - 词池 1 个词 → 必抽它（现状语义不变）
   - 全权重相同（全新记录）→ 退化纯随机，与现状一致
   - 0 星已纠正词 → 保留在池里（连对 3 次归零的触发途径），不剔除，权重自然最低
   - 会话内允许重复抽同一词（"词数<题数时重复"语义保持，不破坏连对 3 次归零机制）
3. **验证方式**：不靠肉眼——构造测试数据（如 10 词 wrongCount 1-10 + 不同 lastWrongTime），跑万次抽样统计分布，断言高频词/新错词出现率显著更高。
4. **待用户确认的开放参数**：衰减周期（现给 24h 翻倍）、wrongCount 斜率。用户点头后直接实施。
