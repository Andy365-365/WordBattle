## 二、二期加权出题（已完成，证据齐全）

### 改动（唯一功能点）
`PracticeSession.start()`：`records.shuffled()` 纯随机 → `weightedPick` 加权抽样。
- 权重公式：`weight = (1 + wrongCount) * 2^(-小时数/24)`
- **公式方向勘误**：上一版交接文档写的 `2^(+小时数/24)` 是正指数笔误——按其文字
  语义（"时间衰减：最近答错翻倍，7 天前衰减到 1/8"）实现为负指数。
  若按正指数实现，最久前的错词权重最高，与"优先练最近/最多错的词"的产品意图完全相反。
  代码注释里已注明勘误原因，需求文档如需同步可再改。
- 边界语义与旧纯随机一致：空池→空、1 词必抽、全权重相同→退化纯随机、
  0 星已纠正词保留池内（连对 3 次归零的触发途径不破坏）、会话内允许重复。
- 其余链路（buildQuestion/submit/连对3次归零/星级写库）零改动。
