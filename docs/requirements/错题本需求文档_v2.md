## 一、背景与目标

对战后答错的单词没有后续跟踪。目标：

- 记录对战中的错题，形成按用户隔离的错题本
- 星级体系标记薄弱程度（0-6）
- 提供赛后复盘、错题练习两种回顾/巩固方式
- 数据全部本地（SQLite），不跨设备同步

## 二、页面结构

```
首页
 ├─ 主机+答题
 ├─ 答题
 ├─ 错题本        ← 新增，位于下方按钮区
 │    ├─ 查看错题   ← 按钮 1
 │    └─ 错题练习   ← 按钮 2
 └─ 调试日志
```

## 三、数据模型

### 3.1 错题记录（新增 SQLite 表 wrong_word）

```
WrongWord {
    username: String      // 所属用户
    word_en: String       // 英文单词（记录 key 的一部分）
    direction: String     // "EN_TO_ZH" | "ZH_TO_EN"
    star_level: Int       // 0-6
    wrong_count: Int      // 累计错误次数（含超时）
    last_wrong_time: Long // Unix ms
}
-- 唯一约束: (username, word_en, direction)
```

- 同一英文词的"英→中"和"中→英"是两条独立记录（两个方向薄弱点不同）
- 旧版升级：无历史错题数据，无需迁移（本功能首次引入）

### 3.2 词库模型（结构调整）

- 词库统一存**英文-中文配对**，一个词一条（现有 words.json 的双镜像条目按 page/unit 合并去重为单条）
- 出题时现场组装，方向由主机设置决定：
  - 英→中：题目=英文词，正确答案=中文释义
  - 中→英：题目=中文释义，正确答案=英文词
- **干扰项**：从词库中其他词的对应语言字段（英→中抽中文释义、中→英抽英文词）均匀随机抽 3 个，与正确答案不重复；题库不足时回退用预置 distractors 字段补齐
- 词条字段不变：word、translation、distractors（后备）、page、unit

## 四、对战记录规则

1. 每题结束（收到 REVEAL），**各端本地**把自己该题的选择与 correctIdx 比对：
   - 答错 / 超时（无选择）：按"用户 + 英文单词 + 方向"查找记录，存在则 star_level +1（上限 6）、wrong_count +1、更新 last_wrong_time；不存在则新建 star_level=1
   - 答对：记录存在且 star_level > 0 则 star_level -1；star_level=0 或无记录不动
2. 英文单词从 GO 消息本地取：英→中时 question 即英文词；中→英时 options[correctIdx] 即英文词
3. 主机自己答题：记到主机当前用户名；客户端：记到各自用户名
4. 不通过网络传输星级数据（维持 v1.1 设计）

## 五、功能一：赛后复盘

### 5.1 数据

对战进行中，每题结束记录到本轮临时列表（不持久化）：

| 字段 | 说明 |
|------|------|
| word | 英文单词 |
| question_text | 题目文本 |
| correct_answer | 正确答案文本 |
| user_answer | 用户选择的答案文本，超时为 null |
| is_correct | 是否答对 |
| timed_out | 是否超时 |
| star_before / star_after | 该题处理前后的星级 |

### 5.2 入口

游戏结束排名页（主机 HOST_RESULT / 客户端 PLAYER_RESULT）：
- 本轮有错（答错或超时 ≥1 题）：底部显示"查看错题"按钮
- 全部答对：显示"全部答对"文案，无按钮

### 5.3 复盘页

```
┌─────────────────────────┐
│      本轮错题             │
├─────────────────────────┤
│  X 题答对 / Y 题答错 / Z 题超时 │
├─────────────────────────┤
│  ready | 正确的 | 你选的 | ★1→★2 │
│  ...                    │
├─────────────────────────┤
│  [ 练习这些词 ]  [ 返回主页 ]  │
└─────────────────────────┘
```

- 列表只显示答错/超时的题（答对的在统计里体现）
- "练习这些词"：进入错题练习，题池 = 本轮答错/超时的词（按其记录方向）
- "返回主页"：清空本轮临时列表
- 用户从结算页直接返回主页（不走复盘页）时，临时列表同样清空

## 六、功能二：错题本（查看错题）

### 6.1 入口与布局

首页"错题本" → 错题本主页（"查看错题""错题练习"两个按钮）→ 查看错题页：

```
┌─────────────────────────┐
│  错题本                   │
├─────────────────────────┤
│  ● 中→英    ○ 英→中       │   ← 方向单选过滤
├─────────────────────────┤
│  ready    准备好（做某事）的 │
│  ★★  错3次  2h前          │
│  ...                    │
└─────────────────────────┘
```

- 单选过滤：只显示所选方向的记录
- 每行：英文单词 + 中文释义（两行或一行折叠）+ 星级 + 累计错次数 + 最后错时间（相对时间：X分钟前/小时前/天前/周前）
- 排序：star_level 降序 → wrong_count 降序 → last_wrong_time 降序
- **归零（star_level=0）的词保留在列表**，显示 0 星，系统不自动清理

### 6.2 删除

- 左滑显示"删除"按钮（用户认为已掌握才删）
- 删除 = 整条记录删除（wrong_count 等全部清零）；该词以后再答错，从零重新记
- star_level ≥ 1 的记录删除前弹确认；star_level = 0 直接删
- 空列表显示"还没有错词，继续保持！"

### 6.3 数据隔离

- 所有查询按当前用户名过滤（多用户隔离，承接《多用户实现计划》阶段三）

## 七、功能三：错题练习

### 7.1 入口与题池

| 入口 | 题池 |
|------|------|
| 错题本主页 → "错题练习" | 当前用户全部错题记录（star_level 任意，含 0 星） |
| 复盘页 → "练习这些词" | 仅本轮答错/超时的词 |

- 题池为空：弹窗提示"没有可练习的词，快去对战积累吧"
- 不做星级筛选（用户已确认简化）
- 每个词按其记录的方向出题（同一词两条方向记录都练）
- 题数：5 / 10 / 20 / 30 可选
- 抽题：从题池均匀随机，词数 < 题数时允许重复

### 7.2 出题与交互

- 出题规则与对战一致（题目/答案按方向组装，干扰项从词库随机抽）
- **题目上显示该词当前星级**
- 每题倒计时 10 秒
- 答对 / 答错立即反馈（✓/✗ + "你的选择"标记），2 秒后自动下一题
- **超时与答错同等处理**

### 7.3 星级变更（练习模式）

- 答错 / 超时：star_level +1（上限 6）
- 答对：star_level -1
- **快速降星**：同一词在当前练习会话内连续答对 3 次 → star_level 直接归 0，计数器重置；期间答错则计数器归 0
  - 计数器按单词独立，仅会话内有效，不持久化

### 7.4 练习结束页

```
总题数 / 正确 / 正确率
星级变化：N 个词降星 / M 个词升星
[ 再来一轮 ]  [ 返回主页 ]
```

## 八、本期范围外（后续迭代）

1. **加权出题（二期）**：对战时按主机用户星级加权抽题 weight = 2^star_level（公式沿用 v1.1 文档 4.1）
2. **拍照 OCR 导入词库（单独拆期）**：v1.1 文档第八章内容基本保留，届时单独立项
3. 云同步、导出导入、遗忘曲线、趋势图等（v1.1 第十一章）

## 九、非功能性

- 错题数据本地 SQLite，5000 条以内 <1MB
- 列表页加载 <200ms（500 词量级内存计算即可）
- 不影响对战主流程性能：每题星级更新在本地完成，<5ms

## 十、实施顺序（已与用户确认）

1. **赛后复盘**（临时记录 + 结算页入口 + 复盘页）← 当前
2. 数据层落库（wrong_word 表）+ 对战记录规则
3. 查看错题页（方向过滤 + 删除）
4. 错题练习（含快速降星）
5. 词库单条配对化 + 干扰项随机抽取改造
6. 多用户隔离收尾验证
