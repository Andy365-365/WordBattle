# WordBattle 错题本功能需求文档

**版本：** v1.0 初稿  
**日期：** 2026-08-03  
**状态：** 待评审

---

## 一、背景与目标

### 1.1 背景

当前 WordBattle 对战后，答错的单词没有后续跟踪。用户无法知道自己薄弱的词汇，也无法针对性地复习。

### 1.2 目标

- 记录用户对战中的错题，形成个人错题本
- 通过星级体系标记薄弱环节严重程度
- 错题加权出题，让薄弱词更频繁地出现
- 提供赛后复盘、专项练习、统计查看三种回顾方式

### 1.3 范围

- 仅客户端本地功能，不跨设备同步
- 每台设备独立维护各自的错题数据
- 对战主机无需知道玩家的星级信息

## 二、星级体系设计

### 2.1 星级定义

| 星级值 | 标记显示 | 含义 |
|--------|----------|------|
| 0 | 无 | 正常词，无错题标记 |
| 1 | ★ | 轻度薄弱 |
| 2 | ★★ | 中等薄弱 |
| 3 | ★★★ | 比较薄弱 |
| 4 | ★★★★ | 严重薄弱 |
| 5 | ★★★★★ | 极度薄弱 |
| 6 | ★★★★★+ | 最严重（五星上限后再错） |

### 2.2 星级变更规则

**答错时：**
- 当前星级 < 6：星级 + 1
- 当前星级 = 6：保持不变（已达上限）

**答对时：**
- 当前星级 > 0：星级 - 1
- 当前星级 = 0：保持不变

**"答对"的定义：** 该词作为题目词出现时，用户选择了正确答案。该词仅作为干扰选项出现时不计入。

### 2.3 错题词数据模型

每个单词除题库原有字段外，额外维护以下本地数据：

| 字段 | 类型 | 说明 |
|------|------|------|
| star_level | int (0-6) | 当前星级 |
| wrong_count | int | 累计错误次数（手动移除前不清零） |
| last_wrong_time | timestamp | 最后一次答错的时间 |

### 2.4 持久化

- 错题数据存储在客户端本地（SQLite 或 SharedPreferences）
- 对战时不通过网络传输星级数据
- 每局对战结束后批量更新星级

## 三、功能一：加权出题

### 3.1 权重计算公式

```
weight = 2 ^ star_level
```

具体映射：

| star_level | weight |
|------------|--------|
| 0 | 1 |
| 1 | 2 |
| 2 | 4 |
| 3 | 8 |
| 4 | 16 |
| 5 | 32 |
| 6 | 64 |

### 3.2 出题流程

**步骤 1：计算权重**
- 遍历题库所有词，根据 star_level 计算 weight
- 求所有词 weight 之和 total

**步骤 2：加权随机采样**
- 在 [0, total) 范围内生成随机数
- 按累积权重区间定位抽中的词
- 重复 N 次（N = 本局总题数）

**步骤 3：去重处理**
- 如果题库总词数 >= 2 × N：抽出的词尽量不重复，若抽到已出现过的词则重新抽取（最多重试 3 次，仍重复则保留）
- 如果题库总词数 < 2 × N：允许重复

**步骤 4：生成干扰项**
- 干扰项从题库中均匀随机抽取，不参与加权
- 干扰项与正确答案不重复

### 3.3 影响范围

- 对战模式出题
- 单人练习模式出题（不适用加权，见功能三）
- 不影响干扰项生成

## 四、功能二：赛后复盘

### 4.1 触发条件

一局对战结束后（收到 GAME_OVER 消息），自动进入复盘流程。

### 4.2 本轮错题记录

对战进行中，每题记录以下信息到本轮临时列表：

| 字段 | 说明 |
|------|------|
| word | 题目单词 |
| correct_answer | 正确答案文本 |
| user_answer | 用户选择的答案文本 |
| is_correct | 是否答对 |
| star_before | 答错前星级 |
| star_after | 答错后星级 |

### 4.3 复盘页面流程

**场景 A：有错题（本轮存在答错的题目）**

```
游戏结束页（排名）
       ↓
底部显示 "查看错题" 按钮
       ↓
点击 → 错题列表页
       ↓
[顶部] 本轮错题统计：X 题答对 / Y 题答错 / Z 题超时
       ↓
[列表] 每题一行：
  单词 | 正确答案 | 你的答案 | 星级变化（如 ★★→★★★）
       ↓
[底部] "练习这些词" 按钮（跳转单人练习，仅练本轮错题）
       │
       └── "返回主页" 按钮
```

**场景 B：全部答对**

```
游戏结束页（排名）
       ↓
底部显示 "全部答对，太厉害了！"
       ↓
无 "查看错题" 按钮
```

### 4.4 数据清理

- 本轮错题临时列表仅在本次对战结束后保留
- 用户离开复盘页面（返回主页或进入练习）后，临时列表清空
- 星级数据持久化保留，不受清理影响

## 五、功能三：单人练习模式

### 5.1 入口

主页新增"练错词"按钮。点击时进行判断：

- 错题本为空（无 star_level ≥ 1 的词）：弹窗提示"错题本为空，快去对战积累吧"
- 有错词：进入练习设置页

### 5.2 练习设置页

```
┌─────────────────────────┐
│       练错词设置         │
├─────────────────────────┤
│                         │
│  总题数                  │
│  ○ 5 题  ● 10 题 ○ 20 题 │
│                         │
│  星级筛选                │
│  ● 全部  ○ 3星及以上      │
│  ○ 5星及以上 ○ 五星加号    │
│                         │
│  ┌───────────────────┐  │
│  │     开始练习       │  │
│  └───────────────────┘  │
└─────────────────────────┘
```

### 5.3 练习出题规则

- 从符合条件的词池（满足星级筛选条件）中均匀随机抽取
- **不适用加权**（用户已经在错题池里，不需要再加权）
- 干扰项生成规则与对战一致

### 5.4 练习交互流程

```
┌─────────────────────────┐
│    单词                   │
│    [ 选项 A ]            │
│    [ 选项 B ]            │
│    [ 选项 C ]            │
│    [ 选项 D ]            │
│                          │
│    倒计时 ████████░░ 10s │
└─────────────────────────┘
         ↓ 选择后
┌─────────────────────────┐
│    单词                   │
│    [ 选项 A ✓ ]          │
│    [ 选项 B ✗ 你的选择 ] │
│    [ 选项 C ]            │
│    [ 选项 D ]            │
│                          │
│    答对！星级 ★★★→★★      │
│    （2秒后自动下一题）     │
└─────────────────────────┘
```

- 每题倒计时：10 秒（与对战一致）
- 答对/答错立即反馈，不等待超时
- 2 秒后自动进入下一题
- 星级按标准规则变更（答对 -1，答错 +1）

### 5.5 快速降星规则

为加速清理错题，练习模式下增加连续答对机制：

**计数器：`session_correct_streak`**
- 按单词独立维护，仅在当前练习会话内有效
- 每次该单词作为题目出现：
  - 答对：计数器 + 1
    - 计数器达到 3：该词 star_level 直接归零，计数器重置
  - 答错：计数器重置为 0

**示例：**
- 词 A 当前 4★，练习中出现 3 次都答对 → star_level = 0，该词移出错题本
- 词 A 当前 4★，练习中出现 2 次答对、第 3 次答错 → 计数器归零；星级变为 5★

### 5.6 练习结束页

```
┌─────────────────────────┐
│      练习完成             │
├─────────────────────────┤
│                         │
│    总题数：10            │
│    正确：8 题            │
│    正确率：80%           │
│                         │
│    星级变化：            │
│    3 个词降星            │
│    2 个词升星            │
│                         │
│  ┌───────────────────┐  │
│  │      再来一轮      │  │
│  └───────────────────┘  │
│  ┌───────────────────┐  │
│  │      返回主页      │  │
│  └───────────────────┘  │
└─────────────────────────┘
```

## 六、功能四：错词统计面板

### 6.1 入口

主页新增"错题本"按钮。

### 6.2 面板布局

```
┌─────────────────────────┐
│        错题本             │
├─────────────────────────┤
│  总错词：42  │ 高危：8  │
│  五星加号：2              │
├─────────────────────────┤
│ ★★★★★+ abandon 错6次 3h前│
│ ★★★★★  receive  错5次 1h前│
│ ★★★★    because  错4次 2d前│
│ ★★★      effect   错3次 5d前│
│ ★★       conduct  错2次 1w前│
│ ★         simple   错1次 2w前│
│ ...                        │
└─────────────────────────┘
```

### 6.3 顶部汇总区

| 指标 | 计算方式 |
|------|----------|
| 总错词数 | star_level ≥ 1 的词数 |
| 高危词数 | star_level ≥ 4 的词数 |
| 五星加号词数 | star_level = 6 的词数 |

### 6.4 错词列表

**排序规则（三级排序）：**
1. star_level 降序
2. wrong_count 降序
3. last_wrong_time 降序（最近错的时间排前面）

**每行信息：**
- 星级标记（★ 符号）
- 英文单词
- 错误次数
- 最后错误时间（相对时间格式：X 分钟前 / X 小时前 / X 天前 / X 周前）

**交互：**
- 左滑显示"移出错题本"按钮
- 点击确认后：该词 star_level = 0（从列表中移除），但 wrong_count 和 last_wrong_time 保留
- 如果再次答错，星级从 0 重新开始上升

### 6.5 空状态

无错词时显示：
```
┌─────────────────────────┐
│                         │
│       (笑脸图标)         │
│                         │
│    还没有错词            │
│    继续保持！            │
│                         │
└─────────────────────────┘
```

## 七、数据模型详细说明

### 7.1 错题本地存储

```
WrongWordEntry {
    word: String          // 英文单词
    star_level: int       // 0-6
    wrong_count: int      // 累计错误次数
    last_wrong_time: long // Unix timestamp
}
```

### 7.2 数据更新时机

**对战中（主机模式）：**
- 主机本地答题时，收到 REVEAL 后立即更新本机星级

**对战中（客户端模式）：**
- 客户端收到 REVEAL 后立即更新本机星级

**批量更新方式：**
- 每题结束后即时更新，不等到整局结束

### 7.3 数据初始化

- 首次安装：所有词 star_level = 0
- 题库更新（如新增词）：新词 star_level = 0
- 不清除历史星级数据（除非用户手动移除）

---

## 八、非功能性需求

### 8.1 性能

- 加权出题计算应在 50ms 内完成
- 错题本页面加载应在 200ms 内完成
- 单机错题数量不设上限，但预期在 500 词以内

### 8.2 存储

- 错题数据占用不超过 1MB（预估 5000 词条 × 每条约 200 字节）

### 8.3 兼容性

- 旧版本升级后，所有词默认 star_level = 0
- 不对旧题库做迁移处理
