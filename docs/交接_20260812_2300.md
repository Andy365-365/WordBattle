## 1. 今日修复的问题

### 1.1 REVEAL 匹配格式错误（关键 bug）
- **问题**: 脚本用 `round=N` 匹配，但日志实际格式是 `"round":N`（JSON）
- **影响**: REVEAL 永远检测不到，每轮白等 15 秒超时，30 轮 = 7.5 分钟
- **修复**: 改为 `f'"round":{go_round}'` 匹配 JSON 格式
- **连带修复**: 正确解析 `"correctIdx":N`（之前用 `text=...` 正则，不对）

### 1.2 游戏结束后脚本卡死
- **问题**: 第 30 题 REVEAL 后游戏结束，脚本继续等 GO 信号
- **修复**: 检测 pending 中出现"游戏结束"立即退出答题循环

### 1.3 tail -f 子进程未清理
- **问题**: `tail -f` 子进程在脚本退出时仍在运行，导致 shell 进程挂起（status=running 但实际已完）
- **修复**: 答题循环结束后 `terminate()` + `kill()` 清理

### 1.4 选项坐标校准（动态查找）
- **问题**: 硬编码 X=480，choice=3 永远点不到
- **修复**: GO 后 dump UI → `find_answer_buttons()` 动态解析按钮中心坐标
- **结果**: 4 个选项全部能点到，分布均匀

### 1.5 答题日志增强
- 每次点击显示：`[题N] 主机选择选项X (cx, cy) (共M次)`
