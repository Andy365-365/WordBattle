## 五、已知数据层瑕疵（✅ 已修复 @ v2.2-20260817-2124）

WrongWordRepository 的 `Json { ignoreUnknownKeys = true }` **没开 `encodeDefaults`** 的问题已修：
`starLevel=1`/`wrongCount=1` 等默认值序列化时被省略、持久化 JSON 字段时有时无、数据不自洽。
- 修法（已在第5步落地）：`Json { ignoreUnknownKeys = true; encodeDefaults = true }`
- 真机验证：用答题序列把 wolf 记录最终落到 starLevel=1（恰好是默认值），读库确认
  `"starLevel":1` 已显式写盘（旧代码此情形字段会被省略）。
- 当前测试机 wrong_words.xml：wolf（starLevel=1, wrongCount=5, EN_TO_ZH），测试刷的脏数据，
  用户打开错题本能看到，可手动删除，不影响代码。

## 六、测试环境（新会话必读 docs/测试纪律.md）

- 测试机：Redmi K20 Pro，序列号 b054d001，USB ADB
- 日志：主机跑 `python3 /data/wordbattle/scripts/log_receiver.py`，接收 8765 端口 UDP 日志
  到 /data/wordbattle/logs/remote_all_YYYYMMDD.log；App 侧日志断了（接收端挂）会触发熔断，
  修复方式 = 重启 receiver + `adb shell am force-stop com.wordbattle`
- 装包：`python3 /data/wordbattle/scripts/auto_install.py 0.5 <apk路径>`
- 读库：`adb shell "run-as com.wordbattle cat /data/data/com.wordbattle/shared_prefs/wrong_words.xml"`
- 收尾铁律：息屏（KEYCODE_POWER，确认 mWakefulness=Asleep）+ screen_off_timeout 恢复 600000
  （测试脚本会改成 2147483647 防息屏，**每次跑完必查**，脚本 atexit 已自动恢复但不可全信）
- 验证版本：日志里搜 `App started.*VERSION` 应等于 DebugLog.kt 里的版本号

- /tmp/parse_ww.py：解析 wrong_words.xml
- 脚本坑：
  ① uiautomator dump 一次约 1s，5s 答题窗口内别在 tap 前 dump；
  ② 读日志必须按 mtime 选文件（曾按 size 选中旧日志白排查半天）；
  ③ Compose 按钮文本可能带后缀（"查看错题（5 题）"），正则用前缀匹配；
  ④ 主机设置页方向 RadioButton 在文本**左侧**，按"钮右缘最贴近文本左缘"配对，
     拿 y 坐标当 x 比会选错方向（曾点错）；
  ⑤ 连续开多局时上一局 TCP server 可能残留 → EADDRINUSE + startGame 0 人 + GO 不下发，
     每局开始先 `am force-stop` 干净启动，并从日志确认 `startGame: N人` 且 N≥1。

## 八、下一步（第 6 步）要点

- 目标：多用户隔离收尾验证（多用户体系阶段三，数据按用户名隔离的收尾确认）

- 建议验证点（开工前先跟用户对齐）：

  - 删除 A 的词不影响 B

- 铁律不变：先出方案对齐 → 用户点头 → 才写代码；改完 build.sh 编译 → 真机验证 → commit+push+tag
