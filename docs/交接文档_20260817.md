## 五、⚠️ 已知数据层瑕疵（未修，附建议）

WrongWordRepository 的 `Json { ignoreUnknownKeys = true }` **没开 `encodeDefaults = true`**。
后果：`starLevel=1` 的记录序列化时该字段被省略（默认值不写盘），加载时又回落到默认 1。
- 当前行为等价、不报错，但**持久化 JSON 里字段时有时无，数据不自洽**，且 starLevel 若未来
  默认值改动会有隐患。
- 建议修法（一行）：`Json { ignoreUnknownKeys = true; encodeDefaults = true }`。
- 当前测试机 wrong_words.xml 实况（4 条，测试数据，全是 EN_TO_ZH）：
  - wolf：starLevel 字段缺失（按默认=1），wrongCount=3
  - send：starLevel 字段缺失（按默认=1），wrongCount=3
  - tear：starLevel=2，wrongCount=5
  - protect：starLevel=0（已纠正，练习中答对降下来的），wrongCount=3
- 这些是测试刷出来的脏数据，用户打开错题本能看到；可手动删除，不影响代码。

## 六、测试环境（新会话必读 docs/测试纪律.md）

- 测试机：Redmi K20 Pro，序列号 b054d001，USB ADB
- 日志：主机跑 `python3 /data/wordbattle/scripts/log_receiver.py`，接收 8765 端口 UDP 日志
  到 /data/wordbattle/logs/remote_all_YYYYMMDD.log；App 侧日志断了（接收端挂）会触发熔断，
  修复方式 = 重启 receiver + `adb shell am force-stop com.wordbattle`
- 装包：`python3 /data/wordbattle/scripts/auto_install.py 0.5 <apk路径>`
- 读库：`adb shell "run-as com.wordbattle cat /data/data/com.wordbattle/shared_prefs/wrong_words.xml"`
- 收尾铁律：息屏（KEYCODE_POWER，确认 mWakefulness=Asleep）+ screen_off_timeout 恢复 600000
  （测试脚本会改成 2147483647 防息屏，**每次跑完必查**，脚本 atexit 已自动恢复但不可全信）
- 验证版本：日志里搜 `App started.*VERSION` 应等于 DebugLog.kt 里的版本号
