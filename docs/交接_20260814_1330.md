### 问题发现

ANSWER 没有被服务器收到。App 端点击按钮后，虽然按钮 onClick 被触发，但 ANSWER 消息没有被 TcpClient 发送出去。

---

## 下一步

需要排查 App 端 ANSWER 提交逻辑，确认为什么 tap 触发按钮后 ANSWER 没有被 TcpClient 发送。

**可能原因**：
1. `tcpClient?.send()` 中 tcpClient 为 null
2. ANSWER 消息格式不对
3. 网络层问题

**排查方向**：
- 检查 TcpClient 的 send 方法是否正确调用了 socket.write()
- 检查 ANSWER 消息的 JSON 格式是否与 TcpServer 期望的一致
- 检查是否有日志记录 ANSWER 发送失败
